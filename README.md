# MxScout

**Video management for MOBOTIX cameras** - by Dialsoft LLC.

- Finds the MOBOTIX cameras on your network, logs in, and shows them live in layouts and grids
  (laid out like MOBOTIX MxControlCenter).
- Plays back and exports recordings straight from the file server / NAS your cameras record to -
  all cameras in sync on one timeline. Export to MP4 or the original .MXG.
- Updates itself automatically.

## Download
Two ways to get MxScout - same program, pick one:

- [**MxScout-Setup.exe**](https://github.com/Dialsoft/mxscout-releases/raw/main/MxScout-Setup.exe) - **installer.**
  Installs for your Windows account (no administrator rights needed), adds MxScout to the Start menu and Desktop,
  and can be removed from Windows Settings > Apps. Silent install for IT: `MxScout-Setup.exe /S`
- [**MxScout.exe**](https://github.com/Dialsoft/mxscout-releases/raw/main/MxScout.exe) - **standalone.**
  One file, nothing to install: save it anywhere (or on a USB stick) and run it.

Both keep themselves up to date and use the same cameras, layouts and settings.
Windows 10 / 11. If Windows shows "Windows protected your PC", click **More info > Run anyway**.
