# MxScout

**Video management for MOBOTIX cameras** - by Dialsoft LLC.

- Finds the MOBOTIX cameras on your network, logs in, and shows them live in layouts and grids
  (laid out like MOBOTIX MxControlCenter).
- Plays back and exports recordings straight from the file server / NAS your cameras record to -
  all cameras in sync on one timeline. Export to MP4 or the original .MXG.
- Updates itself automatically.

## Download
[**MxScout.exe**](https://github.com/Dialsoft/mxscout-releases/raw/main/MxScout.exe) - one file, nothing to install.
Windows 10 / 11. If Windows shows "Windows protected your PC", click **More info > Run anyway**.
